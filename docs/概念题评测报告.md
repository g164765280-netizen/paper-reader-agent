# 概念题评测报告（PaperQA2 流程）

> 对应 `docs/概念题交接文档.md` 第四节。数字题通路见 `docs/数字题评测报告.md`。

## 概览

- 答题模型：**本地 Qwen3-8B**（vLLM 起服务 `:8000`，免费；`enable_thinking=False` 关思考）
- 检索/证据层：**PaperQA2**（paper-qa 2026.8.12 + litellm）
- embedding：**本地 bge-m3**（sentence-transformers，CPU）
- 语料：**109 篇**论文全文（fulltext JSON 的 `pages_text`，约 6.0M 字符，切成 1261 个 chunk）
- 题目数：**20 道概念题**（来自 `导师评测基准30题.md` 的知识题，含金标准关键点）
- 评分：**LLM-as-judge**（API `qwen3.8-max`，独立第三方，避免自评）

## 三维评分结果

| 维度 | 定义 | 得分 | 比例 |
|---|---|---|---|
| grounded（有出处） | 回答是否建立在真实引用论文段落之上，不编造 | 19/20 | **95.0%** |
| relevance（答到点） | 是否命中金标准关键点 | 15/20 | **75.0%** |
| honesty（诚实） | 信息不足时是否诚实，不瞎编 | 18/20 | **90.0%** |

## 分析

**通路已闭环**：本地 Qwen3-8B + PaperQA2 能对 109 篇论文做带出处的概念问答，grounded 率 95%，说明引用基本都落在真实论文段落上（无大面积编造）。

**知识短板（relevance 75%）集中在 5 题**，属于小模型固有局限，非管道问题：
- 概念表述不精确：cq03/cq06/cq13 答到了方向但没点出金标准要求的精确术语（"多尺度/金字塔""密集连接""浅层特征"）。
- cq09（弱监督标注）：模型答"单日期语义标注"，偏离标准答案"图像级标注"——对"弱监督"这个细分概念掌握不准。
- cq12（SECOND）：把遥感语义变化检测数据集 SECOND 与 3D 点云检测模型 SECOND 混淆——同名实体歧义导致的典型幻觉。
- cq14（配准误差）：错误归因，是 20 题里唯一 grounded 也判 0 的（引用失实）。

## 关键实现要点（避坑，供后续复用）

1. **aadd 必须传文件路径**（`.txt`），不能直接传文本字符串——否则 `md5sum(path)` 和 `read_doc` 都会失败（Errno36 文件名过长）。
2. **aadd 也要传 settings**，且 `Settings(llm=...)` 之外还要设 `summary_llm`（默认仍是 gpt-4o，会报"Missing credentials"）。
3. **本地 vLLM 关思考**：`litellm_params` 里加 `"extra_body": {"chat_template_kwargs": {"enable_thinking": False}}`，否则 Qwen3 思考污染答案。
4. **contexts 提取字段**：paperqa 2026.8.12 的 `Context` 顶层是 `id`(pqac-xxx)/`context`(文本)/`text`(Text 对象)/`score`，引用标记 `pqac-xxx` 对应 `Context.id`，论文出处要从 `ctx.text.doc.citation` / `ctx.text.name` 取。
5. **judge 不能截断 contexts**：答案引用的 chunk 可能排在第 9/10 条，只传前 8 条会让 judge 误判"编造引用"。应按答案里实际引用的 pqac-id/chunk 名过滤后再传给 judge。
