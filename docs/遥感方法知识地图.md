# 遥感变化检测方法知识地图

> 这是"遥感科研导师"的领域知识底座。目标：当新生问"变化检测怎么做/选什么方法/为什么 OA 不能当主指标"时，导师能按这张图分层讲解、给出方法演进脉络、实现要点和实验陷阱。
> 标注「⚠️待查证」的条目是近期/细分方向，方法名需进一步核对原文，不可当权威。

---

## 0. 总览：三层分类树

变化检测（Change Detection, CD）—— 识别同一区域不同时期影像的"地表变化"。

```
变化检测
├─ 按监督方式（最常被问的分类）
│   ├─ 全监督   （像素级标注）
│   ├─ 半监督   （少量标注 + 大量未标注）
│   ├─ 无监督   （无标注）
│   ├─ 弱监督   （图像级/粗标注）
│   ├─ 跨域     （训练域 ≠ 测试域）
│   ├─ 开放词汇 （文字引导，零样本）
│   └─ 多模态   （光学 + SAR / LiDAR 等）
├─ 按架构
│   ├─ CNN（卷积）
│   ├─ Transformer（注意力）
│   └─ Mamba / 状态空间（长序列高效）
└─ 按任务粒度
    ├─ 二值变化检测 BCD（变/不变）
    └─ 语义变化检测 SCD（变 + 变成什么类型）
```

---

## 1. 全监督（Fully Supervised）—— 最成熟，是默认起点

**定义**：需要像素级变化标注（每个像素标"变/不变"，SCD 还要标变化类型）。

### 1.1 经典 CNN 路线（2018 起点，必讲）

| 方法 | 核心思想 | 记忆点 |
|---|---|---|
| **FC-EF**（Early Fusion） | 双时相影像**先拼接再编码** | 最简单，信息在输入端融合 |
| **FC-Siam-conc** | 孪生网络，两个分支**权值共享**分别编码，再拼接 | 孪生 + 拼接 |
| **FC-Siam-diff** | 孪生 + 特征**相减** | 差分特征，强调"变化"信号 |

**为什么先讲这三个**：它们是变化检测的三种最基础融合范式（早融合 / 孪生拼接 / 孪生差分），后面几乎所有方法都在这三种上扩展。

### 1.2 孪生网络增强

- **SNUNet（Siam-NestedUNet）**：密集连接 + 多尺度特征聚合，缓解浅层细节丢失。经典，常做基线。

### 1.3 Transformer 路线（2021 后主流，必讲）

| 方法 | 核心思想 | 记忆点 |
|---|---|---|
| **BIT** | 把双时相特征转成 token，用 Transformer 建模**长距离/全局依赖** | token 化 + 全局注意力 |
| **ChangeFormer** | **层次化** Transformer，多尺度金字塔 + 细节分支 | 层次化 + 多尺度 |
| **Changer** | 强调特征聚合的 Transformer 变体 | 聚合设计 |

**为什么 Transformer 兴起**：CNN 感受野受限，对"大范围地物整体变化"（如成片建筑/道路）不如全局注意力；但 Transformer 计算量大、细节易丢，所以层次化 + 多尺度是主流折中。

### 1.4 近期路线（⚠️ 待查证具体名称）

- **Mamba / 状态空间模型**（如 ChangeMamba、Vim 类）：线性复杂度建模长序列，主打"比 Transformer 省算力"。2024 后的热点方向。
- **大模型 / 基础模型微调**：用 SAM、遥感大模型做变化检测，近期趋势。

### 1.5 实现要点（新生最容易忽略）

1. **双时相影像必须配准**（几何对齐），否则直接产生伪变化。
2. **张量拼接/差分**是核心操作，决定信息怎么融合。
3. **损失函数**：二值变化常用交叉熵 / Dice；不平衡时加 Focal Loss。
4. **数据增强**：随机裁剪、翻转，注意保持双时相"配对"关系。

### 1.6 指标（必背，且要懂为什么）

| 指标 | 含义 | 变化检测里的坑 |
|---|---|---|
| **F1** | Precision 和 Recall 调和平均 | 变化检测的**主指标**（最常用） |
| **IoU** | 交集/并集 | 对边界敏感，反映分割质量 |
| **OA** | 整体准确率 | **严重失真**——见下方"实验坑" |
| **Precision / Recall** | 误报 / 漏检 | 看应用偏重哪个 |

### 1.7 实验陷阱（新生最该被提醒的）

1. **为什么 OA 不能当主指标**：变化像素占比通常极小（<5%），模型全预测"不变"也能拿到 95%+ 的 OA，但没有意义。**类别严重不平衡**是变化检测的核心问题。
2. **配准误差 → 伪变化**：两期影像没对齐，边界处会大面积误检。
3. **小目标漏检**：小型建筑变化容易被下采样/池化抹掉，需多尺度。
4. **季节/光照变化 → 伪变化**：植被随季节变化不是真的地表变化。

## 2. 半监督（Semi-supervised）

**定义**：少量有标注 + 大量未标注影像。

**核心思想**：用未标注数据的一致性/伪标签辅助训练。

- **常见范式**：教师-学生模型、伪标签 + 置信度过滤、一致性正则化（对未标注数据加扰动，要求输出一致）。
- **适用场景**：标注成本高（像素级标注很贵），但有大量无标注影像。

**实验陷阱**：伪标签质量差会"带偏"模型；置信度阈值难调。

---

## 3. 无监督（Unsupervised）

**定义**：完全无标注。

**传统方法（必讲，是理解基础）**：
- **CVA（Change Vector Analysis）**：算两期影像每个像素的"变化向量"，模长大 → 变化。
- **PCA / 差异图**：差分后做主成分分析，突出变化。

**深度方法（⚠️ 待查证具体名称）**：
- 深度聚类、自编码器重构误差、生成对抗（用 GAN 生成正常/异常来检测变化）。

**适用/局限**：无需标注，但精度普遍低于监督方法；适合快速筛查或标注困难的场景。

---

## 4. 弱监督（Weakly supervised）

**定义**：只有比像素级更粗的标注（如图像级"有没有变化"）。

- **典型**：CAM（类激活图）类方法，从图像级标签反推像素级变化区域。
- **适用**：标注成本极低，但定位精度有限。

---

## 5. 跨域（Cross-domain）

**定义**：训练和测试的影像分布不同（不同传感器、分辨率、地区）。

- **两种目标**：域自适应（目标域有少量无标注数据）/ 域泛化（目标域完全未知）。
- **核心难题**：训练域的伪变化/纹理和测试域不同，模型泛化差。
- **适用**：真实落地场景（换一个卫星/地区就换分布）。

---

## 6. 开放词汇 / 零样本（Open-vocabulary / Zero-shot）

**定义**：用文字（如"新增建筑"）引导检测，不针对每个类别单独训练。

- **技术路线**：CLIP 类视觉-语言模型，文字和影像对齐。
- **状态**：⚠️ 遥感变化检测里还是较新/研究性方向，落地成熟度低。

---

## 7. 多模态（Multimodal）

**定义**：结合多种数据源，如光学 + SAR、光学 + LiDAR。

- **动机**：光学受云/光照影响，SAR 全天候；多模态互补。
- **核心难题**：不同模态特征对齐/融合（模态差异大）。
- **适用**：需要全天候、抗云遮挡的场景。

## 9. 给导师的"讲解顺序"建议（教学维度）

当新生问"变化检测入门怎么学"，按这个顺序讲：

1. **先讲任务定义**：什么是变化检测、双时相、配准前提。
2. **再讲三种基础融合**（FC-EF / conc / diff）—— 建立"怎么融合两期信息"的直觉。
3. **再讲监督方式**（全/半/无/弱/跨域）—— 建立"我有多少标注"决定路线的直觉。
4. **再讲架构演进**（CNN → Transformer → Mamba）—— 建立"全局 vs 局部"的直觉。
5. **最后讲指标和坑**（F1 为什么是主指标、OA 为什么失真、配准/不平衡/小目标）—— 建立"怎么评估"的直觉。
