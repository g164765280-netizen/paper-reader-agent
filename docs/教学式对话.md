# 教学式连续对话（Teaching Dialogue）

> 这是"遥感科研导师"最核心、也最难的增量。难点不在技术，在**教学**：怎么记住用户学到哪了、怎么递进、怎么判断他听懂没、卡住了怎么换讲法。
> 借鉴 NORA 的 `MEMORY.md`（会话记忆）机制，但把记忆内容从"研究进度"换成"学习状态"。

---

## 一、核心设计：一份"学习状态"记忆

每个用户一份持久记忆文件，导师每轮对话**先读、再答、答完更新**（和 NORA 的 stop hook 自动更新是同一个思路）。

```markdown
# 用户学习状态

## 基本信息
知识水平：研一新生 / 会 CV 没做遥感 / 做变化检测半年 / ...
当前目标：理解概念 / 复现某论文 / 改进某方法 / 写论文 / ...
研究方向：变化检测（建筑场景）

## 已解释过的概念（避免重复，也用于递进）
- [x] 变化检测定义、双时相、配准前提
- [x] 三种基础融合（FC-EF / conc / diff）
- [ ] Transformer 为什么兴起
- [ ] 监督方式分类（全/半/无/弱）
- [ ] 指标（F1 为什么是主指标、OA 为什么失真）

## 当前卡点 / 未回答的问题
- "我的模型小目标漏检严重，怎么改？"（已给出多尺度方向，未确认是否理解）
- "半监督和弱监督区别？"（待解释）

## 推荐下一步（导师给的可执行建议）
- 先复现 FC-EF，再读 BIT 论文，对比两者感受野差异
```

**关键机制**：
1. **已解释概念用复选框**：导师能看到"哪些讲过、哪些没讲"，决定下一步讲什么。
2. **卡点单独记**：用户没懂的问题单独列，下次优先确认。
3. **下一步可执行**：不是"多读论文"，而是"复现 FC-EF"这种具体动作。

## 二、教学循环（每轮对话的流程）

```
1. 读记忆 → 知道用户水平、讲过什么、卡在哪
2. 问背景（首次）或确认上次卡点是否解决（后续）
3. 讲一个概念：先给直觉 → 再给细节 → 再给例子
4. 确认理解：用反问 / 小例子验证（"如果两期影像没配准，会发生什么？"）
5. 根据反馈分支：
   ├─ 懂了 → 记入"已解释"，推荐下一步，进入下一概念
   ├─ 没懂 → 换讲法（换比喻 / 换例子 / 降低难度），不重复原话
   └─ 追问新问题 → 先记入"卡点"，再决定现在答还是放到合适时机
6. 更新记忆 → 结束本轮
```

## 三、教学原则（rubric 的落地）

对应 `导师评测设计.md` 的 7 个维度，这里是具体做法：

| 原则 | 具体做法 | 反例 |
|---|---|---|
| **先了解背景** | 首次问"你之前接触过深度学习吗？做过分割吗？" | 直接甩一篇论文 |
| **难度递进** | 按知识地图的讲解顺序（任务定义→基础融合→监督→架构→指标） | 上来就讲 Mamba |
| **确认理解** | 讲完反问一个具体问题 | 讲完就问"还有问题吗" |
| **可执行** | "复现 FC-EF，代码在 XX，先跑通再改" | "多读论文多实践" |
| **诚实** | 不确定时明说"这块我不确定，建议查 X" | 编造方法细节 |
| **有结构** | 先给总览，再分层展开 | 东一句西一句 |
| **溯源** | "这个方法来自 BIT（Chen et al.），核心是 token 化" | 凭空说 |

## 四、和 NORA / PaperQA2 的分工

```
教学式对话（本文档）—— 管"怎么教"
  ├─ 读/写学习状态记忆
  ├─ 递进 + 确认理解 + 换讲法
  └─ 需要"讲事实"时，调 PaperQA2（证据层）拿带出处的结论
        └─ 需要"走研究流程"时，调 NORA 技能（文献/想法/实验）
```

**关键分工**：教学式对话是"教法"，PaperQA2 是"事实来源"，NORA 是"研究流程"。三者分开，各管各的。

## 五、第一版可落地的实现（不依赖训练）

先用强模型 + 一份 System Prompt + 一个"学习状态"文件，跑通最简教学循环：

1. **System Prompt**：把上面的"教学循环 + 7 原则 + 记忆读写规则"写成系统提示词。
2. **记忆文件**：每个用户一个 markdown，导师用工具读写。
3. **评测**：用 `导师评测设计.md` 的 3 场景 + 7 维 rubric 打分。

第一版不需要训练模型，用强模型（Claude/GPT-4o/本地大模型）就能跑通体验，积累真实对话后再蒸馏。

---

*诚实边界：教学式对话是"教育学 + 产品"问题，不是接个框架就有的；上面的循环和原则是第一版，需真实对话里迭代。*
