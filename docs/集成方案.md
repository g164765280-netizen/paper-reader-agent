# 遥感科研导师 — 集成方案

> 重构方向：用成熟开源项目做底座，增量开发遥感专属的"科研导师"能力。本文档记录对两个底座项目的实测理解 + 集成架构 + 运行时决策。

---

## 一、两个底座项目的实测结论

### NORA（night_owl_research_agent）

**本质**：不是 Python 框架，是**一套 Claude Code 技能**（每个技能 = 带 YAML 头部的 Markdown 提示词）。

```
skills/          研究流程技能（lit-review → synthesis → gap → hypothesis → ... → paper）
memory/MEMORY.md  会话记忆（Markdown，hook 自动更新）
templates/remote_sensing/  IEEE TGRS / ISPRS JPRS / remote_sensing_env 模板
harness/hooks    停止时自动更新记忆的钩子
```

**关键结论**：
- 它的价值在**工作流结构 + 详细的技能提示词 + 记忆机制**，不在代码。
- 原生依赖 Claude Code（Anthropic API），没有 Python 入口。
- **可移植性**：技能是 Markdown prompt，可以抽出来套进自己的 agent harness（换成别的模型跑）。

### PaperQA2（paper-qa）

**本质**：成熟的科学文献 RAG 包（`pip install paper-qa`），v5。

```
- 输入：本地 PDF / 文档 / 源码
- 检索：agentic 证据搜索 + 证据排序 + 上下文摘要
- 输出：带出处回答（citation）、矛盾发现、历史答案索引
- 模型：LiteLLM（可接本地 Ollama/vLLM + 本地 sentence-transformers embedding）
```

**关键结论**：
- **可直接替换手写 RAG**（我们手写 RAG 无泄漏实测只有 45.1%，没有理由不换）。
- 本地可跑：LiteLLM 接 Qwen3-8B + bge-m3 embedding。

## 二、集成架构

```
遥感科研导师 Agent
│
├─ 对话层（我们要开发的增量）
│   ├─ 遥感问题理解器：用户问题 → {领域/任务/场景/模态/监督/输入输出/难点/指标/目的}
│   ├─ 教学式对话：跟踪 {知识水平/当前主题/已解释概念/未答问题/下一步}
│   └─ 方法知识地图：领域知识底座（docs/遥感方法知识地图.md）
│
├─ 工作流层（NORA 的结构，抽技能提示词）
│   文献调研 → 空白发现 → 研究想法 → 新颖性检查 → 方法细化 → 实验设计 → 审查 → 报告
│
└─ 证据层（PaperQA2，替换手写 RAG）
    120 篇遥感论文 → 证据排序 → 带出处回答 → 矛盾发现
```

**职责划分**：
- PaperQA2 管"证据与事实"（哪篇论文、什么结论、出处）。
- NORA 管"研究流程"（怎么从问题走到论文）。
- 我们管"教学"（怎么让新生听懂、怎么递进、怎么适配）。

## 三、运行时决策（待定，需确认）

"第一版用强模型跑通体验"的"强模型"有三个选项：

| 选项 | 优点 | 代价 |
|---|---|---|
| **Claude（NORA 原生）** | 零改造，直接用 NORA | Anthropic API 成本 + 需确认网络可通 |
| **Qwen3-30B-MoE（本地，已有）** | 免 API 成本，本地可控 | 需确认能跑动复杂研究流程 |
| **GPT-4o（LiteLLM）** | 强、稳 | OpenAI API 成本 |

**我的倾向**：先确认服务器能否访问 Anthropic/OpenAI API。若可，第一版用 Claude 跑 NORA 原样（最快出体验）；若不可，用本地 Qwen3-30B-MoE + 适配版 harness。

---

## 四、落地顺序（按依赖关系）

1. **装 PaperQA2**：`pip install paper-qa`，用 120 篇论文 + Qwen3-8B 跑通，验证它是否真的比手写 RAG 好（用 v3 无泄漏评测集对比）。
2. **做遥感问题理解器**：一个 prompt/工具，把用户问题结构化成九元组。
3. **做教学式对话**：借鉴 NORA 的 MEMORY.md 机制，维护用户学习状态。
4. **跑通体验**：强模型 + NORA 工作流 + PaperQA2 证据 + 教学层，积累真实"新人-导师"对话。
5. **评测 + 蒸馏**：用 `导师评测设计.md` 的 rubric 打分，稳定后蒸馏给 Qwen3-8B。
